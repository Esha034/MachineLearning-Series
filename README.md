## 🎯 Learning Approach

My approach to learning each Machine Learning concept is:

1. Understand the fundamental theory behind the concept.
2. Learn the mathematical intuition wherever applicable.
3. Explore the concept with practical examples.
4. Implement the concept using Python and Jupyter Notebook.
5. Experiment with datasets and analyze the results.
6. Document important learnings, notes, and observations.
7. Push the completed work to this repository.
